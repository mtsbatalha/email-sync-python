CLI Documentation

This application runs as a web server. Start it from the command line:

npm start
# or for development with auto-reload:
npm run dev

Limitations
  • No delta sync: Every sync copies all emails from source. Duplicate emails may appear if you sync the same mailbox twice.
  • No deduplication: The app does not check whether an email already exists in the destination.
  • Large attachments: Emails with very large attachments may time out depending on server settings.
  • IMAP only: Only IMAP protocol is supported. POP3 and Exchange EWS are not supported.
  • Self-signed certificates: TLS certificate validation is disabled to support servers with self-signed certs. Use on trusted networks only.
  • No scheduling: Sync must be started manually. There is no automated/scheduled sync feature.
